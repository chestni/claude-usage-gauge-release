# Claude Usage Gauge

Панель для VS Code: спидометры лимитов Claude (5 часов и неделя), прогноз, контекст диалога,
кнопки Compact / Clear.

**Скачать:** [claude-usage-gauge.zip](https://github.com/chestni/claude-usage-gauge-release/releases/latest/download/claude-usage-gauge.zip)

Установка: распакуйте архив и скажите своему Claude Code
«установи по INSTALL.md из этой папки». Подробности — в `INSTALL.md` внутри архива.
